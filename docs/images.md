# Photographies d’ambiance

Ces photographies libres servent à valider la façade, la composition et les animations. Elles ne montrent pas les réalisations de Siray Signature. Afficher discrètement « Photographies d’ambiance » et rendre les crédits accessibles depuis le pied de page.

Source de licence : [Unsplash License](https://unsplash.com/license), consultée le 18 novembre 2026. Chaque page officielle sélectionnée affichait la mention d’usage gratuit sous cette licence. Aucun visuel Unsplash+ ni photographie de Grolet, Louis Vuitton ou Hermès. Toutes les images ont été inspectées visuellement.

Les trois variantes de chaque image ont un côté long maximum de 1 600, 1 024 et 640 pixels : `/images/nom.webp`, `/images/nom-1024.webp`, `/images/nom-640.webp`. Les variantes portrait ont donc une largeur inférieure à ces valeurs. Utiliser les dimensions réelles fournies dans `image-credits.json` pour les descripteurs `srcset`.

## Remplacement par les photographies de Siray

Remplacer la photo principale et toutes ses variantes ensemble. Conserver un `alt` décrivant ce qui est réellement visible, adapter le point focal à chaque nouvelle composition, puis mettre à jour les crédits. Ne pas appeler ces images « nos réalisations » et ne pas en déduire saveurs, recettes, tailles ou tarifs. `gateau-creme.webp` est un gâteau d’ambiance : son format bento n’est pas établi.

Le manifeste JSON contient les URL sources, auteurs, licence, catégories, dimensions, poids et variantes. Les téléchargements bruts de recherche ne font pas partie du site.
